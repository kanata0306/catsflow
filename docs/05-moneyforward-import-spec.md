# Catsflow × マネーフォワード ME 連携仕様

- 文書状態：方針確定／取得手段・実CSV確認後に詳細確定
- 更新日：2026-10-14

## 1. 目的

マネーフォワード MEに集約された家計簿と資産推移をCatsflowに取り込み、LINE Mini Appから家計・資産をまとめて確認できるようにする。

## 2. 方針

- 自動同期の可否を最優先で調査する
- 利用可能な公式API・公式連携手段が確認できれば、その利用条件に従って自動同期を検討する
- 公式の自動取得手段が利用できない場合、ユーザーがダウンロードしたCSVをLINE公式アカウントへ送信し、受信後の処理を自動化する
- LINEでファイルを受信する仕様・制約が合わない場合、LINE Mini App内のファイルアップロードを利用する
- 非公式スクレイピングやMEのログイン情報をCatsflowに保存する方式には依存しない

## 3. 対象データ

### 3.1 入出金履歴／家計簿CSV

取得可能な項目例：計算対象、日付、内容、金額（円）、保有金融機関、大項目、中項目、メモ、振替、ID。

用途：
- 支出・収入の明細表示
- 月次収支の集計
- 予算と実績の比較
- カテゴリ別支出の集計

### 3.2 資産推移CSV

取得可能な項目例：日付、合計（円）、預金・現金・暗号資産、株式（現物）、投資信託、債券、FX、保険、不動産、年金、ポイント、その他の資産。

用途：
- 資産総額の推移
- 資産カテゴリ別の推移・構成
- 資産の前回記録との差分表示（同じ基準日の比較など、計算ルールを定義した場合）

注意：資産推移CSVは口座ごとの内訳をダウンロードできない。口座別・銘柄別の資産情報を取得できるとは想定しない。

公式案内ではCSVダウンロードはプレミアム会員向けで、アプリ版とWeb版で取得方法・範囲が異なる。最新の操作手順と出力形式は公式ヘルプおよびユーザーが取得したサンプルを確認する。

公式ヘルプ：https://support.me.moneyforward.com/hc/ja/articles/49505374073497-%E5%AE%B6%E8%A8%88%E7%B0%BF%E3%83%87%E3%83%BC%E3%82%BF%E3%81%AF%E3%83%80%E3%82%A6%E3%83%B3%E3%83%AD%E3%83%BC%E3%83%89%E3%81%A7%E3%81%8D%E3%81%BE%E3%81%99%E3%81%8B

## 4. データ取り込みフロー

1. CSVをLINEトークに送信、またはMini Appからアップロードする
2. ファイルサイズ・拡張子・文字コード・CSV構造を検証する
3. ヘッダーを基に入出金CSV／資産推移CSVを判定する
4. 一時領域で読み込み、必須項目・日付・金額などを検証する
5. 入出金明細は外部IDを優先して既存データと照合する
6. 資産推移は日付・取得元を基準にスナップショットとして保存する
7. DBトランザクション内で保存し、失敗時は部分取り込みを防ぐ
8. 追加・更新・重複スキップ・エラー件数をLINEへ返信する
9. 同期履歴と最終成功日時を記録する
10. 一時ファイルは処理後に削除する方針を優先する

## 5. 重複・訂正の扱い

- 同一ファイルの再送で二重登録しない
- 入出金CSVのIDを第一候補として重複判定する
- IDがない場合の複合キーは、実データの特徴を確認して設計する
- 振替明細は支出・収入と区別し、二重計上を避ける
- 計算対象フラグを保持し、集計対象から除外するルールを既存Catsflowと整合させる
- 既存明細の修正・削除を検知できるかはCSV仕様を確認して決める
- 資産推移CSVの同一日付再取り込みは加算せず、同一データならスキップ、差分があれば更新する

## 6. 同期状態

同期実行ごとに、少なくとも以下を管理する。

- 同期元・ファイル種別
- 開始日時・終了日時
- 成否
- 読み込み行数・追加件数・更新件数・重複スキップ件数・エラー件数
- エラー概要（秘密情報や明細内容を過剰に保存しない）
- 最終成功日時

## 7. 追加候補の論理データ構造

既存スキーマ確認後に実際のEntity・テーブル設計を決める。候補となる責務：

- 同期設定／連携状態
- 同期実行履歴
- 外部明細IDとCatsflow明細の対応
- 資産推移スナップショット
- 必要であればカテゴリ別資産額の保存

これらは論理的な候補であり、テーブル名やカラム名を確定するものではない。既存テーブルで安全に表現できる場合は重複した構造を追加しない。

## 8. セキュリティ

- LINE Webhookの署名を検証する
- Mini Appからのアップロードは認証済みユーザーと結び付ける
- ファイルサイズ・拡張子・内容を検証し、CSV内の値を実行しない
- 一時ファイルを公開ディレクトリに置かない
- ログにアクセストークン、連携コード、メモ、明細内容などを出力しない
- 他ユーザーの取り込みデータにアクセスできないよう、保存・参照時に認可する
