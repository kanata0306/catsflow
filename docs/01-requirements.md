# Catsflow 要件定義書

- 更新日：2026-10-16
- 文書状態：目的・大方針は確定／詳細要件は実装・データ確認後に確定
- 対象：Catsflow、LINE公式アカウント、LINE Mini App、マネーフォワード MEデータ取り込み

## 1. 目的と提供価値

Catsflowは、家計・資産・負債の情報を統合し、月次評価とAIによる継続的な計画支援を通じて、ユーザーの長期的な資産形成を支援する。

短期的な支出の単発分析を主目的としない。マネーフォワード MEやGPTで代替しやすい「今月何に使ったか」の分析だけでなく、過去の実績・目標・負債・投資状況を継続して蓄積し、計画と実績の差を評価して次の行動につなげる。

### 提供価値

1. 一定フォーマットによる月次評価
2. 貯金・資産形成目標の設定と進捗管理
3. 資産・負債・純資産の一元管理
4. 投資銘柄ごとの積立計画と投資信託全体の資産推移管理
5. AIによる目標達成計画の提案・振り返り支援
6. LINEからの手軽な状況確認と通知
7. 家計簿・簿記的な考え方を用いた二重計上の抑制と財産変化の把握
8. 生活プロフィールを踏まえた個人別の資産形成支援
9. 純資産・生活防衛資金・長期目標・将来シミュレーションの一元管理
10. データの出所・訂正履歴・評価根拠を確認できる透明性

## 2. 方針一覧

| 項目 | 状態 | 方針 |
|---|---|---|
| アプリの主目的 | 確定 | 長期的な資産形成の継続支援 |
| 月次評価 | 確定 | 一定フォーマットで毎月評価する |
| データ取得 | 確定 | マネーフォワード ME中心＋Catsflow内の手動登録・修正 |
| 簿記 | 確定 | 実用的な家計管理を優先。複式簿記の完全実装は必須にしない |
| 負債管理 | 確定 | 残高・金利・返済情報を保持し、評価に含める |
| 投資管理 | 確定 | Catsflowで銘柄名・毎月の投資額を管理し、MoneyForward MEの資産推移CSVから投資信託全体の資産額を取得する。個別銘柄の評価額・損益・保有数量・取得単価は初期版の対象外 |
| AIの役割 | 仮決定 | 計画・評価・選択肢の提案。ユーザー承認なしに金融データを変更しない |
| フロントエンド | 仮決定（既存方針） | LINE Mini App（React + TypeScript）を主画面とする |
| バックエンド | 現状確認 | Java / Spring Bootを継続利用 |
| 開発用DB | 現状確認 | H2を利用 |
| 本番DB・ホスティング | 未決定 | 永続化・バックアップ・費用・運用要件を確認後に決定 |

## 3. 対象ユーザーと利用シーン

- 毎月の収支、純資産、負債残高を振り返りたい
- 貯金目標の金額と期限を決め、必要な月額を把握したい
- 借金返済と貯金・投資の配分を比較したい
- 銘柄ごとの積立計画と、投資信託全体の資産推移を確認したい
- 目標未達の原因と翌月の改善行動を、過去の実績も踏まえて検討したい
- LINEから簡単な状況確認を行い、詳細はMini Appで確認したい

## 4. 機能範囲

### 4.1 初期開発の優先範囲（仮決定）

1. 既存のLINE連携とユーザー紐付けの安定化
2. マネーフォワード MEの入出金CSV取り込みの検証・重複防止
3. 手動登録・修正のためのデータ管理ルール
4. 資産・負債の基本情報と基準日時点残高の管理
5. 月次評価の計算ルールと保存形式
6. 貯金・資産形成目標の管理
7. 投資銘柄・毎月の投資額の管理と、投資信託全体の資産額取り込み
8. LINE／Mini Appでの確認導線

実装順は既存コード・認証・DBの調査後に確定する。詳細な銘柄管理とAI助言を同時に作り始めず、データ整合性を先に整える。

### 4.2 後続機能・追加予定候補

以下は将来の追加候補であり、今回の更新時点で実装済み・初期リリース必須と確定したものではない。実装順・詳細仕様は別途決定する。

- **純資産・資産構成の可視化**：資産総額、負債総額、純資産の推移と構成を表示
- **長期目標・達成予測**：金額・期限・進捗を管理し、現在の計画での達成見込みを試算
- **月次レビュー・改善履歴**：一定のフォーマットで毎月評価し、前月との差と翌月の行動を記録
- **生活防衛資金の管理**：生活費等をもとに現金確保の目安を設定し、現在額と比較
- **生活プロフィール**：住居形態、本人負担の生活費、収入の安定性、家族への支援、今後の予定、本人の優先事項などを任意登録
- **将来シミュレーション**：積立額変更、返済優先、引っ越し、収入変化、臨時出費など複数条件を比較
- **LINE通知・定期レポート**：月次レビュー案内、目標進捗、予算超過等を通知
- **データ訂正・変更履歴**：手動修正、インポート更新、プロフィール・目標の変更履歴を追跡
- **AI評価の根拠・データ充足度表示**：使用した数値、未取得項目、事実と試算の区別を表示
- 猫の経験値・レベル・称号・成長履歴
- 対応可能なデータソースが確認できた場合の資産・投資データ取り込み自動化

## 5. 月次評価の基本要件

月次評価は少なくとも以下を分けて表示する。

- **家計収支**：収入、支出、収支
- **貯蓄実績**：計画に対する貯蓄額・貯蓄率
- **資産・負債**：資産総額、負債総額、純資産
- **負債返済**：残高変化、返済額、元金・利息の内訳（取得可能な範囲）
- **投資**：銘柄別の積立計画（銘柄名・月額）と、資産推移CSVから取得した投資信託全体の評価額。個別銘柄の評価額・損益は初期版では算出しない
- **目標進捗**：目標額・期限・進捗率・見込み達成時期
- **データ品質**：基準日、最終更新日時、未取得項目、手動入力・推定値の区別
- **評価と次の行動**：根拠となる数値、改善候補、翌月の具体的な行動
- **評価の透明性**：実績値・ユーザー入力値・計算値・将来試算・AI提案を区別し、データの不足や基準日差を明示する
- **生活背景（後続候補）**：生活プロフィールを評価に利用する場合、本人が登録した事実とAIによる解釈を分け、未入力の事情を推測しない

計算できない項目はゼロとして扱わず、「未取得」「未設定」「計算不可」などの状態を明示する。

## 6. 家計簿・実用的な簿記要件

- 収入・支出・口座間振替・投資資金移動・負債元金返済・利息を区別する。
- 口座間振替を支出として二重計上しない。
- 投資口座への資金移動を、投資商品の購入と家計消費の両方に重複計上しない。
- 負債の元金返済と利息を可能な範囲で区別する。
- 元金返済は現金を減らす一方で負債も減らすため、純資産評価で単純に二重のマイナスにしない。
- 既存データの金額符号ルールは現状確認後に統一する。既存スキーマ・データの移行方針を決めずに一括変更しない。
- 完全な借方・貸方の仕訳帳や会計基準への準拠は初期要件に含めない。

## 7. マネーフォワード ME連携要件

- 公式に利用可能な自動取得手段があるか、利用条件・料金・取得範囲を確認する。
- 自動取得手段が使えない場合、ユーザーが取得したCSVの取り込みを基本経路とする。
- 取り込みデータと手動入力データの出所・更新日時を追跡できるようにする。
- 同一明細の再取り込みによる二重登録を防ぐ。
- 入出金CSVと資産推移CSVを別のデータ種別として扱う。
- 資産推移CSVに個別銘柄・口座別保有情報が含まれるとは仮定しない。
- 手動修正が再インポートで意図せず上書きされないよう、元データとユーザー修正の扱いを設計する。

## 8. セキュリティ・プライバシー

- 認証済みユーザー自身のデータだけを参照・変更できる。
- LINEユーザーIDやアカウント連携情報をクライアント入力だけで信用しない。
- LINE Webhookの署名検証とイベント再送対策を行う。
- チャネル秘密情報、アクセストークン等をソースコードに直書きしない。
- CSVのサイズ・形式・列・値を検証する。
- ログに取引メモ、認証情報、連携コードなど不要な個人情報を出さない。
- CSV一時ファイルの保存要否・保持期間・削除方法を決める。

## 9. 初期版の受け入れ条件（提案）

- LINEの既存コマンドが連携済みユーザーに対して正しく応答する。
- ユーザー間で家計・資産・負債データが混在しない。
- 同一CSVの再取り込みで二重計上しない。
- 収支・資産・負債・純資産の計算ルールを説明でき、テストで検証できる。
- 手動登録・修正とインポートデータの出所を区別できる。
- 月次評価を同じフォーマットで再生成できる。
- 目標の過去設定と過去評価が、後日の目標変更で書き換わらない。
- データ未取得時に推測値を実績として表示しない。
- 既存の認証方式・DB構造との整合性を確認したうえで実装する。

## 10. 未決事項

- マネーフォワード MEの公式自動取得手段の有無、費用、条件
- 実CSVの列名・文字コード・値の形式と訂正／削除の表現
- 手動修正と再インポートの優先ルール
- 資産の評価基準日、資産種別と入力粒度
- 銘柄名の入力ルール・積立開始月・積立停止の扱い（必要項目を実装時に確定）
- 負債の初期入力項目、利息・返済予定の管理粒度
- 月次評価の具体的なスコア・判定基準
- AIの利用サービス・料金・入力データ範囲
- LINE Mini Appの実装状態・認証方式・公開設定
- 本番DB、ホスティング、バックアップ、運用費
- 猫の成長条件と月次評価との連動
- 生活プロフィールの必須・任意項目、更新タイミング、保存期間
- 生活防衛資金の計算方式（何か月分を目安とするか等）
- 目標達成予測・シミュレーションの前提条件と不確実性の表示
- LINE通知の種類、頻度、通知停止設定
- データ変更履歴の保存範囲・保持期間・ユーザー向け表示
- AI評価のデータ充足度や信頼度をどのように説明するか
