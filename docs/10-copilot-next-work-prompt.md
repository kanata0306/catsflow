# Copilot 次回作業プロンプト

このファイルは `docs/09-additional-specification.md` の付録Aと同じプロンプトを、次回作業時にコピーしやすいよう独立させたものです。

次回のCatsflow作業では、まず既存リポジトリと設計書を調査し、追加仕様との差分・未決事項・実装計画を作成します。**最初のフェーズではコードやDBを変更せず、調査レポートを提示して停止する**ことをCopilotに指示します。

詳細な指示は、`docs/09-additional-specification.md` の「付録A：次回作業開始時にGitHub Copilotへ渡すプロンプト」を使用してください。
