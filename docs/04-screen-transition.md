## 3. LINEトーク側の遷移（概念）

```mermaid
flowchart TD
    A[LINE公式アカウント] --> B{受信内容}
    B -- 今月 --> C[家計収支サマリー]
    B -- 予算 --> D[予算状況]
    B -- カテゴリ別 --> E[カテゴリ別支出]
    B -- 将来：資産 --> F[資産・純資産サマリー]
    B -- 将来：負債 --> G[負債・返済状況]
    B -- 将来：目標 --> H[目標進捗]
    B -- CSV --> I[ファイル受付可否を検証]
    I --> J[CSV検証・取り込み]
    J --> K[取り込み結果]
    B -- その他 --> L[利用可能なコマンドを案内]
```

LINEでのCSVファイル受信は、Messaging APIの仕様・サイズ制約を実装前に検証する。満たさない場合はMini Appのアップロードを主経路とする。

## 4. ホーム画面の優先情報（仮決定）

1. 最新の純資産と基準日
2. 当月の収支・貯蓄実績
3. 負債残高と返済進捗
4. 長期目標の進捗
5. 月次評価への導線
6. データの最終更新日時・未取得情報

データが未登録のカードはゼロ表示にせず、登録案内または未取得表示にする。
