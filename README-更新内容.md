## 今回の更新

### 画面構成（現時点の決定）

- 下部ナビゲーションは4項目、左から「ホーム」「資産」「家計」「目標」。
- 「資産」は「家計」より左に配置する。
- 下部ナビゲーション以外の固定ショートカット・固定メニューは設けず、各画面のコンテンツはスクロールさせる。
- ホーム画面は「AIによる月次評価」と「資産推移グラフ」を中心とする。
- ホーム画面に「今月の支出」セクションは置かない。
- 資産推移グラフには、時系列の把握を助ける目印・記憶用マーカーを設ける方向。
- 家計画面は複数選択に対応する。
- 目標画面では目標とライフプランを一体的に見せる。内部データモデルを統合するかどうかは別途判断する。

### MoneyForward MEの取り込み方法（未決定）

- 入出金CSV、資産推移CSV、画面表示情報のコピー＆ペースト等を候補として比較する。
- 取り込み方法・組み合わせ・ユーザー操作フローはまだ採用決定していない。
- 既存文書にある「CSVアップロードを基本経路とする」「資産推移CSVを初期版の確定取得元とする」といった記述は、採用済み仕様ではなく候補・検証対象として読む。
- 実データの列・形式、コピー内容の安定性、取得できる粒度、重複・訂正の扱い、ユーザー作業量を確認してから決定する。
- ユーザーの手作業を不必要に増やさないことを評価軸に含める。

### 投資・資産・負債の扱い

- 投資対象はNISAで管理する方針。
- 初期の投資計画は、銘柄名とユーザーが設定する毎月の投資予定額を管理する。
- 個別銘柄の保有数量・取得単価・取得原価・評価額・損益・売買履歴・配当履歴を初期仕様に含めるとは決めていない。
- 資産推移データは基準日付きのスナップショットとして扱い、過去値に加算しない。最新スナップショットを現在値として扱う。
- ポイントは資産として扱う。
- 長期負債（奨学金・住宅ローン等）は純資産計算に含める。クレジットカード等の短期債務・引落予定は長期負債として純資産から差し引かない。ただしカード利用明細は家計支出として扱う。
- 純資産は、同一基準日の資産（ポイントを含む）から長期負債を差し引いて算出する。

## 2026-11-18 追加仕様更新

今回の追加決定は `docs/09-additional-specification.md` を参照する。同書は同一項目に関する過去の候補・仮案より優先する。

### 確定した方針
- MoneyForward MEの画面コピー＆ペーストによる資産情報取り込みを追加する方向とする。
- 取り込み時は既存資産を照合して更新し、新規資産は追加する。全件削除・全置換は行わない。
- 資産ごとに最新の有効な評価情報を用いて純資産を評価する。評価日時の違いは保持・表示し、一定期間経過したデータには警告を出す。
- 長期負債は独立した管理画面を設け、生活プロフィールからアクセスできるようにする。
- 長期負債の基本項目は負債名・種類・月返済額・メモ。支払い終了予定日は任意項目とする。
- 固定費管理を追加し、生活プロフィールに管理導線を設ける。
- AIによる登録・変更は、ユーザーが内容を確認・承認した後に確定する。

### 未決定・注意事項
- MFコピペの対象画面・実際のコピー形式・取得項目、資産識別キーは実データ確認後に決定する。
- 資産の鮮度警告期間、固定費の確定項目、負債残高の登録・更新方法は未決定。
- 支払い終了予定日から残り期間は表示できるが、残債額・返済率は推測しない。予定日経過だけで自動完済にしない。
- 2026-11-15時点の外部AIへの金融情報・生活プロフィール送信禁止方針は維持する。AI相談の実装・外部AI接続は、別途の方針決定が必要。
- 今回は設計書更新のみ。ソースコード・DBスキーマ・画面は変更していない。
